# Assignment 1 report

The submitted report is the LaTeX report in [latex/](latex/), written with the HCMUT report template (`hcmut-report.cls`). It builds to `latex/build/main.pdf`, which `scripts/package_submission.py` places at the root of the submission ZIP as `Assignment1_Report.pdf`.

The measurements come from the submitter's laptop (Intel Core i7-13620H, 6 performance + 4 efficiency cores, 16 logical CPUs, Windows 11, MinGW-w64 GCC 13.2) on 24 October 2026: run `run-laptop-02` with 711 configurations (P up to 14), plus the separate P=12-16 saturation run `saturation-laptop-01`.

The result tables in `latex/generated/` are produced by `scripts/latex_tables.py` from `results/processed/summary.csv`, and the code listings are read directly from the C++ sources, so neither is typed by hand. After new measurements, regenerate the tables, copy the figures from `results/figures/` into `latex/figures/`, and rebuild from `latex/`:

```bash
latexmk -pdf -outdir=build main.tex
```

`Assignment1_Report_EN.pdf` and `notes.json` belong to the earlier ReportLab edition generated by `scripts/create_report.py`; they are no longer part of the submission.
