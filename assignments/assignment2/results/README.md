# Local results

GitHub chỉ lưu hướng dẫn này. Mọi road extract, raw.jsonl, manifest/environment, validation logs, summary.csv, figures và report sinh ra nằm trong `results-local/`, `validation-local/` hoặc report/ và được ignore.

Benchmark output lưu network.road + road-metadata.json, oracle costs, immutable raw samples, manifest và completion. Summary validate lại raw đầy đủ trước median/IQR. File experiment input được kèm trong ZIP để rerun offline; original slide/đề/notebook không nằm trong ZIP/source publish.

Tóm tắt kết quả thực thi và giới hạn tại [verification.md](../docs/verification.md). README Ass2 có lệnh tái lập.
